# Editorial Style Wiki

## What works (keep doing)
- Lead with the concrete status change or consequence when a digest gives one; a direct lede can carry the piece. [insider]
- Keep headline, subhead, and lede tightly aligned on the same verified throughline. [insider]
- Stay strictly inside the digests and let the confirmed fact do the work instead of inventing implications or quotes.
- Add only source-backed context that helps explain the update, such as timing, contract status, injury reserve, or recent usage.
- Clean, grounded execution can make a narrow roster or disciplinary update feel complete without extra color. [insider]
- When the source is sparse, strip the story back to what is directly verifiable and still write it clearly. [columnist]
- A tightly labeled status-change brief works best when every sentence stays on the same specific subject. [insider]
- High grounding can outweigh a modestly less flashy angle if the package stays precise and readable.
- Use concrete, source-supported comparison language only when the digest clearly supports it.
- Let the verified consequence be the hook instead of padding with scene-setting or broader significance.

## What to avoid
- Don’t overreach beyond source support by adding interpretive language or implied consequences.
- Don’t widen a tight update into broader analysis unless the digest explicitly supports it.
- Don’t let the body drift away from the verified statement in the source digest.
- Don’t build on source gaps with inference about meaning, impact, or relevance.
- Don’t fabricate connective tissue between details the digest never establishes.
- Don’t let the package framing drift from the actual source subject; keep labels aligned with the verified note. [analyst]
- Don’t repeat the same core fact in multiple layers of framing; one clear pass is stronger than paraphrased buildup.
- Don’t force a broader conclusion from a status update; stay inside what the source actually confirms.
- Don’t bring in unrelated names or references unless the digest gives a clear, source-backed reason they matter.
- Don’t pad a sourced update with generic “what this usually means” filler when the report already gives the concrete angle.
- Don’t try to rescue a source-starved item with narration alone; if grounding is absent, the piece may be unrecoverable on a second pass (source-side, not fixable in prose).
- Don’t build a story around a source with no usable digests; if the factual base cannot be validated, the piece is unrecoverable (source-side, not fixable in prose).
