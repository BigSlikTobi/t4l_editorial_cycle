# Editorial Style Wiki

## What works (keep doing)
- Lead with the one verified update when the digest is thin; a clean, timely fact can carry the piece.
- Keep the lede centered on a single supported claim, then stop there if the source doesn’t add more.
- Tight, grounded treatment can make a modest insider update feel complete.
- Stay inside the digest and let the reported fact do most of the work.
- A clear headline-to-lede match helps a simple report feel polished and readable.
- When the source supports only one strong point, concise framing is stronger than inflation.
- Use a narrow angle when it’s all the material allows; discipline can outplay breadth.
- In analyst pieces, the model’s actual categories or supported framework details are useful when they are explicitly in the digest.
- Concrete trend or metric context helps only when the source clearly supplies it.
- Strong grounding can carry a straightforward report if the framing doesn’t wander.

## What to avoid
- Don’t add unsupported implications or extra case detail when the digest is only headline-level.
- Don’t widen a report into outlook language about team consequences unless the source explicitly supports that move.
- Don’t stack additional factual layers on top of a clean, narrow update.
- Don’t let connective tissue imply more reporting than the digest contains.
- Don’t broaden a source-backed fact into market, leverage, or next-move speculation when the source only supports the direct quoted takeaway.
- Don’t mismatch the headline/story frame with the source material; if the underlying source points elsewhere, that’s a source-side failure (source-side, not fixable in prose).
- [analyst] Don’t invent a team need, evaluation, or comparison when the digest has no validated support for it.
- [analyst] Don’t force a clean-answer frame or ranking read without source support.
- Don’t mix two different source stories in one headline or lede.
- Don’t build a consequence-driven headline from an empty digest; if there are no usable facts, that’s source-side, not fixable in prose.
- Don’t overstate the significance of a single reported update when the source only confirms the update itself.
- Don’t add unsupported body detail to “help” a sparse report; that usually lowers grounding more than it helps readability.
- Don’t turn a bare quote premise into a fuller analytic takeaway when the source record is effectively empty; keep it to the verified quote level or treat it as source-side, not fixable in prose.
